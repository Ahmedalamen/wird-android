# وِرد — مشروع أندرويد أصلي (نسخة تطويرية)

هذا مشروع Android Java أصلي **وليس APK** ولا تطبيق ويب. ما زال تجريبياً ولم يُختبر على جهاز فعلي.

## للحصول على APK من GitHub
1. أنشئ مستودع GitHub جديداً وارفع **محتويات** هذا المجلد إلى جذر المستودع.
2. افتح Actions > Build Android APK > Run workflow.
3. بعد نجاح البناء افتح التشغيل ثم Artifacts وحمّل `wird-debug-apk`.
4. فك ضغط الملف الناتج وثبّت `app-debug.apk` على أندرويد (قد يطلب الهاتف السماح بالتثبيت من المصدر).

يتطلب ذلك حساب GitHub. ملف GitHub Actions موجود في `.github/workflows/android.yml`. نجاح البناء لم يُتحقق منه في هذه البيئة؛ إذا فشل، أرسل سجل الخطأ لنصلحه.

## الموجود حالياً
- واجهات Android أصلية بدون WebView، ومتابعة الصلوات، ومؤقت 5 دقائق، وحفظ محلي للتقدم، وسلسلة إنجاز.
- جلب نص صفحات القرآن عبر alquran.cloud بالإنترنت، **ليس مصحفاً أوفلاين مطابقاً للمصحف المطبوع**.
- تشغيل تلاوة السور عبر واجهة MP3Quran بحسب توفر القارئ والسورة، **لم يُختبر التشغيل فعلياً**.

## غير مكتمل — لا تدّعي اكتماله
- تفسير ابن كثير **غير مدمج**؛ الموجود رابط خارجي فقط.
- أقوال ابن الجوزي وابن تيمية وابن القيم والحسن البصري **غير مضافة** حتى توثيق النص والمصدر.
- تنزيل التلاوات، التكرار التلقائي، إشعارات الصلوات، جدولة المراجعة، حماية الستريك، وتدقيق النص والمصادر.
- بناء APK واختباره على جهاز فعلي.

**تحذير:** لا تعتمد على هذه النسخة وحدها لضبط القرآن أو التجويد؛ راجع مصحفاً معتمداً ومعلماً متقناً.
